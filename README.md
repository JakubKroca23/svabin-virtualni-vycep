# Švabín — Virtuální výčep

Jednoduchá 3D aplikace: vyber pivo, otevři, načepuj (hladinka / šnyt / mlíko) a napij se.

Live: https://jakubkroca23.github.io/svabin-virtualni-vycep/

## Lokálně

```bash
npm install
npm run dev
```

Katalog piv se načítá živě z `https://svabin.com/catalog.json` (fallback v `public/data/`).

## Stack

Vite · Three.js (WebGL) · Tailwind · Web Audio SFX
